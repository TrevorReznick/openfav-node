# AI Generated Pages - Implementation Documentation

## Overview
Implementazione completa degli endpoint per la gestione delle pagine AI generate con integrazione Redis e autenticazione utente.

## Redis Key Structure
- **Formato**: `ai_generated_pages:{userId}:{pageId}`
- **Esempio**: `ai_generated_pages:user-123:ai-generated/page-1`

## Nuovi Endpoint Implementati

### 1. Save AI Generated Page
- **Endpoint**: `POST /api/ai-pages/save`
- **Purpose**: Salva una pagina AI generata in Redis
- **Request Body**:
```json
{
  "userId": "user-123",
  "pageData": {
    "pageId": "ai-generated/page-1",
    "page": {
      "id": "ai-generated/page-1",
      "title": "AI Generated Page",
      "content": "This page was generated by AI",
      "createdAt": "2024-02-04T10:31:00Z",
      "updatedAt": "2024-02-04T10:31:00Z",
      "userId": "user-123"
    },
    "prompt": "Generate a test page for Openfav",
    "metadata": {
      "model": "gpt-4",
      "attempt": 1,
      "tokens": { "prompt": 10, "completion": 50, "total": 60 },
      "cached": false,
      "generated_at": "2024-02-04T10:31:00Z"
    }
  }
}
```

### 2. Get AI Generated Page
- **Endpoint**: `GET /api/ai-pages/get?userId={userId}&pageId={pageId}`
- **Purpose**: Recupera una pagina AI generata specifica
- **Query Parameters**:
  - `userId`: ID dell'utente (dall'autenticazione)
  - `pageId`: ID della pagina da recuperare

### 3. Delete AI Generated Page
- **Endpoint**: `DELETE /api/ai-pages/delete?userId={userId}&pageId={pageId}`
- **Purpose**: Elimina una pagina AI generata
- **Query Parameters**:
  - `userId`: ID dell'utente (dall'autenticazione)
  - `pageId`: ID della pagina da eliminare

### 4. Get User AI Generated Pages
- **Endpoint**: `GET /api/ai-pages/user/{userId}`
- **Purpose**: Recupera tutte le pagine AI generate di un utente
- **Path Parameters**:
  - `userId`: ID dell'utente
- **Note**: La ricerca per pattern non è ancora implementata per Upstash Redis

## Integrazione con Autenticazione
- Il `userId` deve essere estratto dalla sessione di autenticazione
- La chiave Redis include il `userId` per isolare i dati per utente
- I metodi validano la presenza del `userId` prima di procedere

## Testing
La collection Postman include esempi di richieste con dati di test per verificare tutti gli endpoint.

## Limitazioni Note
1. **Pattern Search**: Upstash Redis non supporta attualmente la ricerca per pattern. Il metodo `getUserAIGeneratedPages` richiede implementazione aggiuntiva o un indice separato.
2. **Expiry**: Le pagine scadono dopo 24 ore di default.

## Prossimi Sviluppi
1. Implementare ricerca per pattern o indice separato per `getUserAIGeneratedPages`
2. Aggiungere validazione più robusta per i dati della pagina
3. Implementare caching per migliorare le performance
4. Aggiungere logging più dettagliato per debugging
